About the application

ClipperAgent is an AI-assisted video content workflow application currently in development. Its processing components run on an Ubuntu machine operated by the developer.

Potential information processed

Subject to enabled permissions, the application may handle TikTok account identifiers, OAuth tokens, video files, captions, publishing status and diagnostic logs. Actual processing must be confirmed before launch.

Third-party services

The public information website is hosted by GitHub Pages. TikTok API integration, if approved and authorized, exchanges data with TikTok. Other providers and international transfers require assessment before production operation.

Data retention and rights

Retention periods, deletion procedures, security measures and a contact for rights requests will be documented before the service launches.
